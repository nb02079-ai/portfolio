# 이도형 — 자기소개 포트폴리오

GitHub Pages로 배포되는 정적 사이트입니다. 저장소의 소스가 아니라 **아래 주소에서 완성된 페이지로 바로 볼 수 있습니다.**

## 바로 보기

- **포트폴리오 메인** — <https://nb02079-ai.github.io/portfolio/>
- **LinTrace 공격 → 탐지 데모** — <https://nb02079-ai.github.io/portfolio/lintrace/>
- **LinTrace 실제 진단 리포트 원본** — <https://nb02079-ai.github.io/portfolio/lintrace/report.html>

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 메인 — 이야기 · 숫자 · 대표작 · 학습 기록 · 이력서 |
| `lintrace/` | 침해 흔적 진단 도구 LinTrace 데모 — 11단계 침해 사슬 전수 탐지 실증과 리포트 원본 ([소스 저장소](https://github.com/nb02079-ai/lintrace)) |
| `shortcut-check/` | 지름길 점검기 |
| `auth.js` · `schema.sql` | 비공개 섹션 — Supabase Auth Passkey(WebAuthn) |

`main` 브랜치에 푸시하면 GitHub Pages가 자동으로 다시 배포합니다 (반영까지 1~2분, 브라우저 캐시는 새로고침 필요).
