# 지름길 점검기

공개 데이터셋으로 악성코드 탐지 모델을 만드는 학생·연구자가 **데이터셋을 학습에 쓰기 전에**, 특징 하나나 메타데이터 하나만으로 라벨이 얼마나 갈리는지 계산해 "높은 정확도가 지름길에서 나올 수 있다"는 위험을 알려 주는 브라우저 앱입니다.

바탕 논문: 「높은 탐지 성능은 무엇을 측정하는가 — 호스트 행위 기반 악성코드 탐지 평가의 네 층위 분석」 (이도형, 2026)

- 4.1절: CIC-MalMem-2022는 실행 중인 서비스 수 하나로 정확도 99.65%, DMBD 2025는 수집 연도만으로 ROC-AUC 0.907
- 5.3절: 공개 벤치마크를 쓰기 전에 단순한 기준선(깊이 1 결정트리)과 메타데이터-라벨 관계부터 확인할 것

## 내 컴퓨터에서 실행하는 방법

1. 이 폴더를 내려받거나 압축을 풉니다.
2. `index.html`을 브라우저로 엽니다. 서버, 설치, 로그인이 필요 없습니다.
3. "예시 데이터로 해 보기"를 누르거나 내 CSV를 고른 뒤, 라벨 열과 악성 값을 확인하고 "점검 시작"을 누릅니다.

## 데이터와 개인정보

- **예시 데이터**: CIC-MalMem-2022(`Obfuscated-MalMem2022.csv`, 58,596행)에서 정상 1,500행과 악성 1,500행을 무작위로 뽑은 축소본입니다(난수 시드 2022). 메모리 덤프에서 센 숫자 특징 55개와 `Category`(정상은 `Benign`, 악성은 악성코드 계열명·샘플 해시·덤프 번호로 된 파일 이름), `Class`(정답) 열로 되어 있습니다. 사람에 관한 정보는 들어 있지 않습니다.
  - 출처: Canadian Institute for Cybersecurity, University of New Brunswick — <https://www.unb.ca/cic/datasets/malmem-2022.html>
  - 논문: Carrier, T., Victor, P., Tekeoglu, A., & Lashkari, A. H. (2022). Detecting obfuscated malware using memory feature engineering. *ICISSP 2022*, 177–188. https://doi.org/10.5220/0010908200003120
- **사용자가 넣는 파일**: 브라우저 안에서만 읽고 계산합니다. 서버로 보내거나 저장하지 않으며, 새로고침하면 사라집니다.

## 환경 변수와 비밀값

이 앱은 AI 서비스나 외부 API를 부르지 않으므로 **필요한 키와 환경 변수가 없습니다.** 소스에도 키·토큰·비밀번호가 들어 있지 않습니다. 외부로 나가는 요청은 글꼴(Google Fonts)을 불러오는 것 하나뿐이며, 글꼴을 못 불러와도 앱은 그대로 동작합니다.

나중에 AI 기능을 붙이게 되면 키를 소스에 쓰지 않고 서버 쪽 환경 변수(예: `AI_API_KEY`)로만 읽고, 이 절에 변수 이름을 적습니다.

## 판정 기준

| 판정 | 기준 |
| --- | --- |
| 거의 완전 분리 | 특징 하나로 시험 정확도 99% 이상 |
| 지름길 후보 | 90% 이상이거나 다수 클래스 기준선보다 35%p 이상 높음 |
| 메타데이터: 강하게 얽힘 / 어느 정도 얽힘 | ROC-AUC 0.9 이상 / 0.7 이상 |

이 기준은 앱이 정한 값이며 논문이 정한 기준이 아닙니다. 고정 시드 42로 행을 섞어 70%에서 기준값을 정하고 나머지 30%에서 정확도를 잽니다.

## 한계

이 점검을 통과해도 데이터셋이 타당하다는 뜻은 아닙니다. 논문에서도 DMBD 2025는 깊이 1 결정트리 점검을 통과했지만(76.33%), 입력에 없는 수집 연도의 교란은 이 점검으로 잡을 수 없었습니다.
