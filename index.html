About Me

기계공학을 전공하며 설계와 해석을 중심으로 다양한 프로젝트를 경험했습니다. 문제를 발견했을 때 원인을 분석하고, 적절한 도구를 활용해 해결책을 찾는 과정을 중요하게 생각합니다.

문제를 분석하고 최적의 조건을 찾습니다

배터리 냉각 시스템 최적화 프로젝트에서 냉각 조건에 따른 열적 거동을 분석하고 여러 조건을 비교했습니다. 시뮬레이션 결과를 바탕으로 냉각 성능을 판단하고 최적의 조건을 탐색했습니다.

아이디어를 실제 결과물로 구현합니다

자동회피 복싱 로봇 제작 프로젝트에서 로봇의 구조를 설계하고 센서를 활용해 상대방의 움직임을 인식하도록 구성했습니다. 제작 과정에서 발생한 문제를 수정하며 실제로 작동하는 로봇을 완성했습니다.

새로운 기술을 실제 문제에 적용합니다

머신러닝을 활용한 빌딩풍 예측 프로젝트에서 데이터를 분석하고 예측 모델을 구축했습니다. 기계공학적 문제에 데이터 기반 접근법을 적용하며 새로운 기술을 활용하는 경험을 쌓았습니다.

Projects

Battery Cooling System Optimization

전기차 배터리의 열적 안정성과 냉각 성능을 확보하기 위해 냉각 조건을 분석하고 최적의 조건을 탐색한 프로젝트입니다.

Focus: Simulation · Thermal Analysis · Optimization

Project Details

배터리 냉각 조건에 따른 온도 변화를 비교하고 시뮬레이션 결과를 활용하여 냉각 성능을 분석했습니다.

주요 경험: ANSYS · 열해석 · 설계 변수 비교

Auto-Avoidance Boxing Robot

상대방의 움직임을 감지하고 자동으로 회피하는 복싱 로봇을 직접 설계하고 제작한 프로젝트입니다.

Focus: Mechanical Design · Sensor · Control · Fabrication

Project Details

로봇 구조를 설계하고 센서를 활용하여 상대방의 움직임을 인식한 뒤 회피 동작으로 연결되도록 시스템을 구성했습니다.

주요 경험: 구조 설계 · 센서 활용 · 제작 · 문제 개선

Machine Learning-Based Building Wind Prediction

건물 주변에서 발생하는 복잡한 바람의 변화를 머신러닝을 활용해 예측한 프로젝트입니다.

Focus: Machine Learning · Data Analysis · Prediction

Project Details

풍속 및 환경 데이터를 분석하고 머신러닝 기반의 예측 모델을 구축하여 실제 현상과 예측 결과를 비교했습니다.

주요 경험: 데이터 분석 · 머신러닝 · 예측 모델
