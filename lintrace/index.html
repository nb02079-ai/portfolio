LinTrace — 공격을 심고, 전부 잡다

KISA 해킹진단도구에서 출발해 직접 만든 리눅스 서버 침해 흔적 진단 도구입니다. 루트 권한으로 한 번 실행하면 읽기 전용으로 계정·프로세스·네트워크·지속성·파일·로그를 훑어 54개 항목을 점검하고, 심각/위험/정상을 근거와 함께 판정합니다. 아래는 깨끗한 Ubuntu 24.04 웹서버에 직접 공격을 심고 LinTrace로 탐지한 실증 기록입니다.

도구 한눈에

침해가 의심되는 서버에서 "무슨 일이 있었나"를 빠르게 좁히는 라이브 대응(Live-response) 도구.

  • 54개 점검 항목 — 계정(ACC)·지속성(PER)·프로세스(PRC)·네트워크(NET)·파일(FS)·명령 기록(CMD)·로그(LOG), MITRE ATT&CK 매핑
  • 읽기 전용 · 파이썬 표준 라이브러리만 — 점검 대상을 바꾸지 않고, Python 3.6까지 호환(구형 서버에서도 동작)
  • 근거 중심 판정 — 모든 탐지에 이유·근거(로그 줄·파일 해시·프로세스)·다음 확인 단계를 함께 제시
  • 보조 기능 3종 — 기준선 비교 · 사건 타임라인 · 증거 아카이브(지워진 파일 복구 포함)
  • 리포트 3형식 — 텍스트 · JSON · 외부 자원 없는 단일 HTML(CSP·전부 이스케이프)
  • 검증 — 공개 실습 VM 2종(lin.security 18.04, Ubuntu 24.04+WordPress)에서 심어진 권한 상승 경로 8/8 탐지, 기준선 오탐 0, 자동화 테스트 290개

실증: 11단계 침해 사슬 → 전수 탐지

깨끗한 상태의 기준선을 먼저 저장하고, 공격자 관점의 침해 사슬을 심은 뒤 LinTrace를 한 번 실행했습니다. 심은 공격은 하나도 빠지지 않고 잡혔습니다.

탐지를 하나의 사건으로 엮는 보조 기능 3종

기준선 비교

깨끗했을 때를 저장해 두고 달라진 것만 짚습니다. 이번엔 새 포트 4444·UID 0 계정·SUID·cron 생성과 /etc/passwd·authorized_keys 변경 등 7건을 정확히 집었습니다. 재부팅마다 바뀌는 값은 제외해 오탐 0.

사건 타임라인

탐지 흔적의 시각을 모아 공격 진행 순서를 재구성합니다. 1분여에 집중된 자동화 공격임이 드러났고, 다른 실습 VM에서는 사전에 수기로 확인한 공격 순서와 정확히 일치했습니다.

증거 아카이브

탐지 근거 파일을 원본 그대로 보존합니다. 공격자가 지운 접근 로그를 웹서버가 아직 붙잡고 있어(/proc), 삭제된 원본을 그대로 복구했습니다.

원리로 보는 도구 — 돋보인 세 장면

1. 날짜 위장을 꿰뚫다

공격자가 웹쉘의 수정 시각을 2024년으로 돌렸지만, 생성 시각(ctime)은 방금으로 남았습니다. touch는 수정 시각만 바꿀 뿐 ctime은 그 순간으로 찍히기 때문입니다. 타임라인이 둘을 나란히 보여 줘 "최근에 심고 날짜만 위장했다"가 드러납니다. 수정 시각만 봤다면 2년 전 파일로 묻혔을 공격입니다.

2. 흔적을 지우는 손을 포착

공격자가 명령 기록을 /dev/null로 지워 한 통제의 증거는 사라졌지만, 그 삭제 행위 자체를 다른 통제(LOG-03)가 잡았습니다. 한 겹이 지워져도 다른 겹이 지우는 손을 봅니다.

3. 포트가 아니라 본질로 판단

리버스 셸이 외부가 아닌 루프백(127.0.0.1)으로 연결돼 "외부 연결" 탐지는 올바르게 조용했고, 대신 "셸의 입출력이 네트워크 소켓인가"라는 본질을 보는 통제(PRC-08)가 잡았습니다. 포트·IP가 아니라 행위로 판단하기에 루프백이어도 놓치지 않습니다.

도구가 스스로 밝히는 한계

탐지만큼 중요한 것은 결과의 신뢰 범위를 정직하게 말하는 것입니다.

  • 타임라인: "시각은 조작 가능(touch·시계 변경) — 순서는 단서일 뿐 증거가 아니다"
  • 기준선: "기준선이 이미 침해된 뒤 찍혔다면 비교는 소용없다"
  • 읽지 못한 항목은 '정상'으로 세지 않고 '점검 불가'로 따로 밝힌다
  • 리포트는 외부 자원 없는 단일 HTML + CSP로, 웹 로그·웹쉘 속 공격자 문자열이 리포트를 열 때 실행되지 않도록 전부 이스케이프

아래 리포트는 스냅샷으로 복원되는 실습용 VM을 진단한 결과이며, 실제 운영 데이터가 아닙니다. 비밀번호 해시 등 민감 정보는 도구가 자동으로 가립니다.
